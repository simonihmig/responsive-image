# @responsive-image/solid-v2

Solid.js v2 component to render responsive images, provided as locally processed images or loaded remotely from Image CDNs.

Part of the [ResponsiveImage](https://github.com/simonihmig/responsive-image) project.

## Compatibility

- Solid 2.0 or above (RC)

## Documentation

Visit [responsive-image.dev](https://responsive-image.dev) for our complete documentation site.
